Instrução para o Cliente (O "Único Comando"):
Para recriar o ambiente e rodar o projeto, abra o terminal na pasta e siga os passos abaixo:

1. Criar o ambiente: 
   python -m venv .ve_Aula32_Hello

2. Ativar o ambiente (no Windows): 
   .ve_Aula32_Hello\Scripts\activate

3. O Comando Mágico para instalar as dependências: 
   pip install -r requirements.txt

4. Executar o Dashboard:
   streamlit run app-Aula32.py
